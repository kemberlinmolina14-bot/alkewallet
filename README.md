# Alke Wallet 💳 - Evaluación Integradora Frontend

Una aplicación de billetera digital (Fintech) desarrollada como proyecto integrador. La plataforma permite a los usuarios gestionar su saldo simulado, realizar depósitos de fondos de manera segura, transferir dinero a contactos agendados y visualizar un historial dinámico y detallado de sus últimos movimientos financieros.

##  Características Principales
*   **Inicio de Sesión Simulado:** Validación de credenciales con alertas interactivas.
*   **Gestión de Saldo en Tiempo Real:** Persistencia de datos utilizando `localStorage`.
*   **Módulo de Depósitos y Transferencias:** Formularios interactivos con modales de confirmación de éxito.
*   **Buscador con Autocompletado:** Filtrado predictivo sobre la agenda de contactos al transferir.
*   **Historial Dinámico:** Tabla de transacciones automatizada que registra ingresos y egresos al instante.

##  Tecnologías Utilizadas
*   **HTML5:** Estructuración semántica de todas las vistas del sistema.
*   **CSS3 & Bootstrap 4:** Diseño adaptativo (Responsive Design) con una paleta de colores Fintech Premium y transiciones fluidas.
*   **JavaScript & jQuery:** Manipulación dinámica del DOM, validaciones de formularios y control de eventos.
*   **Git & GitHub:** Control de versiones estructurado por ramas independientes de trabajo.
